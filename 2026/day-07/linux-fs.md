# Linux Core Directories Overview

## `/` (Root Directory)

**Description:**  
The root directory is the top-level directory in Linux. All files and directories in the system originate from here.

**Items Seen (ls -l):**
- `home`
- `etc`

**Usage:**  
I would use this when navigating the entire filesystem or understanding the main Linux directory structure.

---

## `/home`

**Description:**  
This directory contains the personal home directories of all users on the system. Each user has their own folder for files and settings.

**Items Seen (ls -l):**
- `maddy`
- `user1`

**Usage:**  
I would use this when accessing user files, personal documents, or user-specific configurations.

---

## `/root`

**Description:**  
This is the home directory for the root (administrator) user and contains files and configurations used by the root account.

**Items Seen (ls -l):**
- `.bashrc`
- `.ssh`

**Usage:**  
I would use this when performing administrative tasks as the root user.

---

## `/etc`

**Description:**  
The `/etc` directory stores system-wide configuration files used by the operating system and installed services.

**Items Seen (ls -l):**
- `passwd`
- `ssh`

**Usage:**  
I would use this when modifying system configuration or troubleshooting services.

---

## `/var/log`

**Description:**  
This directory contains log files generated by the system and applications, which are important for monitoring and debugging.

**Items Seen (ls -l):**
- `syslog`
- `auth.log`

**Usage:**  
I would use this when checking logs to troubleshoot system issues or monitor service activity.

---

## `/tmp`

**Description:**  
The `/tmp` directory is used to store temporary files created by applications and the system. These files may be deleted automatically.

**Items Seen (ls -l):**
- `temp123`
- `systemd-private-*`

**Usage:**  
I would use this when storing temporary files during script execution or testing.

---

# Additional Directories

## `/bin`

**Description:**  
The `/bin` directory contains essential command binaries required for basic system functionality.

**Items Seen (ls -l):**
- `ls`
- `cp`

**Usage:**  
I would use this when running essential Linux commands needed for system operation.

---

## `/usr/bin`

**Description:**  
This directory contains most of the user-level command binaries and applications installed on the system.

**Items Seen (ls -l):**
- `python3`
- `git`

**Usage:**  
I would use this when running installed programs and standard Linux commands.

---

## `/opt`

**Description:**  
The `/opt` directory is used for installing optional or third-party software packages.

**Items Seen (ls -l):**
- `google`
- `custom-app`

**Usage:**  
I would use this when installing or managing third-party applications that are not part of the default system.
